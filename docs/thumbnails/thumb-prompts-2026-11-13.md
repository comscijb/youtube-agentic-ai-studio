# Private Gravity — new thumbnails (GPT Image), 2 options per long-form video

**How to use**
- Paste **one prompt at a time**. Each prompt already contains the shared style, so you don't need to paste anything else.
- Generate in **landscape (1536×1024)**, then crop to **16:9** and export at **1280×720 JPG** (under 2 MB).
- Keep the bottom-right corner free: YouTube puts the duration there.
- **Before uploading, check at phone size** (about 170 px wide): the face or object, and the text, must still read.
- **A/B test:** if "Test & Compare" appears for the video in Studio, upload both options plus the current one. If it doesn't, swap manually: option A now, then option B after 4 days if impressions or CTR don't improve. Change **only the thumbnail**, not the title, so we know what worked.
- Each pair uses two different concepts on purpose: **(A) a face with strong emotion**, **(B) a symbolic object or a scale contrast**. None of them uses the old grey "QUESTION?" formula.
